# Retail Sales Analysis Using SQL

## Project Overview
This project analyzes retail sales transaction data using SQL and Python to identify revenue trends, customer purchasing patterns, and product category performance.

## Dataset
- Records: 1,000 (original dataset)
- Source: Retail Sales Dataset
- Features: Customer information, transaction dates, product categories, quantities, and sales amounts.

## Tools & Technologies
- Python
- SQL
- SQLite
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
1. Overall sales performance
2. Revenue by product category
3. Monthly sales trends
4. Gender-based purchasing analysis
5. Customer age group analysis
6. Top 10 customers by spending
7. Best-selling product categories
8. Highest revenue transactions
9. Weekday sales analysis

## Visualizations
- Category Revenue Analysis
- Monthly Revenue Trends
- Gender-based Sales Distribution
- Age Group Revenue Analysis

## Project Files
- `Retail_Sales_SQL_Analysis.ipynb` – Complete analysis
- `retail_sales.db` – SQLite database
- `retail_sales_outputs.zip` – Graphs and CSV reports

## Project Objective
To develop practical SQL and data analytics skills and extract meaningful business insights from retail transaction data.
